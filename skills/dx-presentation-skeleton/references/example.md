# 出力の見本（A1 稟議）

数字はすべて説明用の仮の値。

## 入力（利用者の状況説明）

> 来月、工場長に溶接ロボット導入の稟議を出す。費用は約8,000万円。現状の溶接手直しは年1,200万円。15分、10枚以内。投影して説明する。

## 出力

## 0. 判定
- パターン：A1 システム投資の稟議
- 理由：判定の質問4「お金の承認がほしい」に該当
- 置いた前提（提案）：効果は手直し費の削減と溶接工数の削減の2つと置いた。工数削減の数字は未入手

## 1. 一番言うべきこと（1文）
溶接ロボットに8,000万円を投資すれば、手直し費と溶接工数を合わせて年約1,700万円削減でき、約4.6年で回収できるため、導入を承認いただきたい。

## 2. 聞き手にしてほしいこと
工場長に、〔会議日〕に8,000万円の投資を承認してもらう。

## 3. 導入の流れ（SCQA）
- S 状況：大型ケーシングの溶接は熟練者の手作業に頼っている
- C 問題・変化：手直しが年1,200万円発生し、熟練者の退職で今後さらに増える
- Q 問い：品質を安定させ、熟練者に頼らない溶接にするにはどうするか
- A 答え：溶接ロボットを導入し、約4.6年で投資を回収する
