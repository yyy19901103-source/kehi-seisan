# 生産センターDX推進 発表資料フレームワーク

三菱重工コンプレッサ株式会社 生産センター 生産技術チーム
対象：生産センターDX（Digital Transformation：デジタルによる業務・事業の変革）推進リーダーの発表資料

## 1. 分類の考え方

資料は「聞き手に何をしてほしいか」で5つの型に分類する。型が決まれば資料の構成が決まる。

| 型 | 聞き手に求めること | 基本構成 |
|---|---|---|
| A 結論先行型 | 承認 | 結論 → 根拠 → 費用対効果 → 依頼事項 |
| B 定点観測型 | 状況の把握 | 予定と実績 → 差異 → 課題 → 次の打ち手 |
| C 問題解決型 | 中身の評価 | 目的・基準 → 結果 → 原因 → 判断 |
| D 説明・展開型 | 理解して動いてもらう | 目的 → 全体像 → 手順・要点 → 守ってほしいこと |
| E 期サイクル型 | 期を通して見てもらう | 期初の計画 → 期中の進捗 → 期末の実績（同じ枠で継続） |

### 2.1 範囲の定義

- **B2 社外情報収集**：技術・知識・見学など、情報収集が目的の展示会・学会・他社見学・出張に限る。仕入先監査や海外工場支援など、情報収集以外が目的の出張は対象外とし、内容に応じて B1 または C1 で報告する。
- **C1 検証**：システム・デバイスなどを社内または社外で実際に検証する場面。机上の新技術調査は C1-1（事前報告）の「事前調査結果」に含める。
- **A4・B1**：DX以外の業務も含む広範囲の資料であり、型Eとは独立して作る。
- **型E**：DXロードマップは年4回（期初・Q2・Q3・期末）報告する。Q2とQ3は同じ構成（E2）を使う。

## 3. 共通ルール

1. 1ページ1メッセージ。ページのタイトルは、そのページの結論を文章で書く。
2. 型Aは1ページ目に結論と依頼事項を置く。
3. 事前報告（B2-1・C1-1）で示した目的・基準を、事後報告（B2-2・C1-2）にそのまま再掲し、対比させる。
4. DXに関する数字（KGI〔Key Goal Indicator：重要目標達成指標〕・KPI〔Key Performance Indicator：重要業績評価指標〕・投資額・効果額）は、型Eの数字を正とする。A4・B1でDXの数字を使う場合は、型Eと同じ値を引用する。
5. 英語の略語とカタカナ語には、初出時に（　）で説明を付ける。
6. 安全・法令遵守・情報セキュリティ・データ主権（データの所有・利用権限）に関わる事項は、該当する場面では必ず1項目として記載する。

## 4. パターン別の標準構成

### 型A：結論先行型

#### A1 システム投資の稟議（8〜10ページ）

1. 結論：承認依頼事項、投資額、期待効果
2. 背景と課題：現状の損失を定量で示す
3. 目的と目標：KGI・KPIと目標値
4. 対策案と代替案の比較
5. 投資額：費用の内訳（初期費用・保守費用）
6. 効果：定量効果・定性効果、回収年数
7. リスクと対策：安全・セキュリティ・現場への影響を含む
8. 日程と体制
9. 承認依頼事項（再掲）

#### A2 ベンダー・機種の選定（6〜8ページ）

1. 結論：推奨するベンダー・機種と理由の要点
2. 選定条件と評価基準（重み付け）
3. 候補一覧
4. 比較評価表（評価基準ごとの点数）
5. 費用比較（導入費用・保守費用・TCO〔Total Cost of Ownership：総保有コスト〕）
6. 推奨理由
7. リスク・懸念と対策
8. 次の手順と依頼事項

#### A3 システムベンダーとの仕様打合せ（5〜8ページ）

1. 本日の目的と決めたいこと
2. 前回の宿題の確認
3. 要求仕様：機能要件・非機能要件（性能・可用性・保守性）
4. 制約条件：設備・ネットワーク・セキュリティ・データ主権
5. 論点と確認事項
6. **合意事項**（必須）
7. **保留事項**（必須）：保留の理由と判断時期
8. **宿題**（必須）：内容・担当・期限

#### A4 年度の方針・予算の説明、目標管理（7〜9ページ）

1. 結論：今年度の方針、重点施策、予算総額
2. 前年度の振り返り：目標と実績
3. 環境変化と課題
4. 方針と重点施策
5. 目標：KGI・KPIと目標値、担当
6. 予算の内訳
7. 体制と日程
8. 依頼事項

### 型B：定点観測型

#### B1 定例の進捗報告（週報1〜2ページ、月報3〜5ページ）

1. サマリー：全体の状況（青・黄・赤）
2. 予定と実績（マイルストーン単位）
3. 差異とその原因
4. 課題とリスク
5. 対策と次の打ち手
6. 依頼事項・相談事項

#### B2-1 社外情報収集の事前報告（3〜5ページ、型A構成）

1. 結論：参加・訪問の承認依頼と費用
2. 目的：何を知りたいか、自社のどの課題に結び付くか
3. 対象：展示会名、学会のセッション、訪問先
4. 確認したい項目：仮説と質問リスト
5. 日程・参加者・費用
6. 期待する成果と報告予定日

#### B2-2 社外情報収集の事後報告（4〜6ページ）

1. サマリー：自社への示唆の上位3点
2. 事前の確認項目に対する結果：分かったこと／分からなかったこと
3. 主な技術・事例
4. 自社への示唆と適用の可能性
5. 次の行動：内容・担当・期限
6. 付録：入手資料、連絡先

#### B3 大学・研究機関との共同研究の報告（5〜7ページ）

1. サマリー
2. 研究の目的・期間・体制
3. 計画に対する進捗
4. 成果：データと考察
5. 課題と次期の計画
6. 知財・契約・データの取扱い
7. 依頼事項

### 型C：問題解決型

#### C1-1 システム・デバイス検証の事前報告（5〜7ページ、型A構成）

1. 結論：検証実施の承認依頼
2. 背景と課題
3. 事前調査の結果：技術動向・候補
4. 検証の目的と仮説
5. 合否の基準（定量で示す）
6. 検証の条件と方法：環境、サンプル数、評価手法（統計手法を含む）
7. 日程・体制・費用
8. リスク：安全・セキュリティ・現場への影響

#### C1-2 システム・デバイス検証の事後報告（5〜7ページ）

1. 結論：合否と導入判断
2. 検証の目的と合否の基準（C1-1から再掲）
3. 検証の条件：計画との差異
4. 結果：基準ごとの合否
5. 原因分析：未達項目の原因
6. 導入判断と導入の条件
7. 次の行動

### 型D：説明・展開型

#### D1 業務標準の展開説明（5〜8ページ）

1. 目的：なぜ変えるか
2. 適用範囲と開始日
3. 全体像：業務フロー
4. 変更点：旧と新の比較
5. 手順と要点
6. 守ってほしいこと：禁止事項、判断基準
7. 問い合わせ先、教育の予定、FAQ（Frequently Asked Questions：よくある質問）

#### D2 工場見学・来客への説明（5〜7ページ）

1. 会社・工場の概要
2. 本日の見学ルートと安全上の注意
3. 見どころ：DXの取り組み事例
4. 成果事例
5. 今後の取り組み
6. 質疑応答

注意：社外向けのため、公開してよい情報かを事前に確認する。

### 型E：期サイクル型（年4回）

E1〜E3は同じKGI・KPI表の書式を使い、期を通して数字を追えるようにする。

#### E1 期初（Q1）：前期の振り返りと今期の計画（8〜10ページ）

1. 結論：今期の目標と重点
2. 前期の振り返り：目標と実績
3. 前期の学び
4. 今期の環境と課題
5. ロードマップ：中期計画の中での位置づけ
6. 今期のKGI・KPIと目標値
7. 重点施策と日程
8. 体制と予算
9. 依頼事項

#### E2 期中（Q2・Q3）：四半期報告（5〜7ページ）

1. サマリー：全体の状況（青・黄・赤）
2. KGI・KPIの予定と実績
3. 施策ごとの進捗
4. 差異の原因
5. 対策と期末までの見通し
6. 依頼事項

#### E3 期末（Q4）：結果と実績の振り返り（6〜8ページ）

1. 結論：達成度
2. KGI・KPIの最終実績
3. 施策ごとの成果
4. 未達の原因
5. 学び
6. 次期への引継ぎ（次期のE1につなげる）
